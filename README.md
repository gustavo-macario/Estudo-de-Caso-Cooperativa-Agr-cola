### Estudo de Caso – Cooperativa Agrícola ###

Repositório com desafios práticos de SQL simulando o banco de dados de uma cooperativa agrícola.
O foco é aplicar consultas analíticas e regras de negócio em um cenário real.

Objetivo:
Demonstrar domínio de:
SELECT e filtros
JOIN (INNER e LEFT)
Funções de agregação (SUM, AVG)
CASE WHEN
CTE (WITH)
Window Functions (ROW_NUMBER, SUM OVER)
Subqueries
Manipulação de datas
Estrutura do Banco

Tabelas utilizadas:
cooperados
culturas
entregas_safra
faturamento

Tecnologias:
SQL
CTE
Window Functions
Funções de agregação
Manipulação de datas

Finalidade:
Projeto voltado para prática de SQL aplicada a cenários de análise de dados e regras de negócio.
